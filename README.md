# 🏦 Personal Finance X-Ray

> AI-Powered Bank & UPI Statement Intelligence System

---

## 📖 Overview

Personal Finance X-Ray is an end-to-end AI-powered financial analysis platform.

The system converts unreadable bank and UPI statements into meaningful financial insights by using:

- 📄 Statement Parsing
- 🧹 Merchant Name Cleaning
- 🤖 Machine Learning Categorization
- 📊 Analytics Engine
- 📈 Spend Forecasting
- 🧠 Retrieval-Augmented Generation (RAG)
- 💬 AI Financial Assistant

---

## 🎯 Project Goals

- Convert raw bank statements into structured data
- Automatically categorize transactions
- Detect recurring subscriptions
- Detect unusual spending patterns
- Forecast future expenses
- Chat with your financial history using AI
